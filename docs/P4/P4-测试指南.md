# P4 S-Core 测试指南

## 一、环境准备

```bash
make clean && make all
make run
# U-Boot 提示符下输入: loadboot
```

## 二、基本功能测试

### 2.1 Shell 启动

输入 `loadboot` 后，内核初始化完成后出现：
```
------------------- COMMAND -------------------
> root@UCAS_OS:
```

说明 shell 已进入用户态并等待输入。

### 2.2 帮助命令

```
> help
Available: ps exec <id> kill <pid> clear help
```

### 2.3 启动 fly（飞机动画 + 抢占调度测试）

```
> exec 1
```

预期：
- `X` 标记 exec 成功
- 输出 `> exec pid=2`
- 飞机 ASCII 动画在屏幕上移动
- Shell 提示符仍然可以输入（定时器中断在 shell 和 fly 之间切换）

```
         _
       -=`\
   |\ ____\_\__
 -=c`""""""" "`)
    `~~~~~/ /~~`
      -==/ /
        '-'
```

### 2.4 启动 lock（互斥锁测试）

```
> exec 2
```

预期循环输出：
```
> [TASK] Applying for a lock.
> [TASK] Has acquired lock and running.(0)
> [TASK] Has acquired lock and running.(1)
...
> [TASK] Has acquired lock and running.(4)
> [TASK] Has acquired lock and exited.
```

### 2.5 启动 rw（内存读写测试）

```
> exec 3
```

预期：
```
0x402008, <random_number>
Success!
```

然后 `sys_exit` 干净退出，不会崩溃。

### 2.6 多进程同时运行

```
> exec 1          # 飞机动画
> exec 2          # 互斥锁
> exec 3          # 内存读写
```

预期：三个程序同时运行，shell 仍然可输入命令。

## 三、进程管理测试

### 3.1 查看进程（ps）

```
> ps
```

预期输出：
```
[PS] PID STATUS
[PS] 1   RUNNING
[PS] 2   READY
[PS] 3   READY
```

STATUS 可能的值：`RUNNING`（当前运行）、`READY`（就绪队列中）、`BLOCKED`（阻塞）、`EXITED`（已退出）。

### 3.2 终止进程（kill）

```
> kill 2
> kill 2 -> 0
> ps
[PS] PID STATUS
[PS] 1   RUNNING
[PS] 2   EXITED
```

- 返回值 `0` 表示成功，`-1` 表示进程不存在或已退出
- kill 后 ps 中该进程 STATUS 变为 EXITED
- 被 kill 的程序停止运行

### 3.3 重新 exec 已退出的进程

```
> kill 2          # 先杀掉 fly
> exec 1          # 重新启动 fly
```

预期：fly 再次启动，`ps` 中看到新的 PID。

### 3.4 清屏

```
> clear
```

## 四、错误处理测试

### 4.1 无效命令

```
> foo
Unknown command: foo
```

### 4.2 exec 无效 ID

```
> exec 99
> exec pid=-1
```

### 4.3 kill 无效 PID

```
> kill 99
> kill 99 -> -1
```

## 五、完整测试流程

```
make clean && make all && make run
# U-Boot: loadboot

> help
> exec 1          # 启动 fly，观察飞机动画
> exec 2          # 启动 lock，观察锁输出
> exec 3          # 启动 rw，观察 Success!
> ps              # 查看进程状态
> kill 2          # 终止 fly
> kill 3          # 终止 lock
> ps              # 确认进程已退出
> clear           # 清屏
> exec 1          # 重新启动 fly
```

## 六、预期正常行为

- Shell 始终可以输入命令（不被其他进程阻塞）
- 飞机动画和 lock 输出不会互相覆盖（光标定位正常）
- kill 命令生效，被 kill 的进程不再输出
- rw 的 `Success!` 后无崩溃（`truly_illegal_insn`）
- exec 多次启动同一 task ID 后 ps 中 PID 递增
